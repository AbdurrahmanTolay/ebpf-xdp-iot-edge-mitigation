# Analysis scripts

These scripts are copied from the completed evidence package used for the manuscript.

- `generate_thresholds.py` implements the offline candidate-threshold calculation used during calibration.
- `final_resource_analysis.py` aggregates accepted resource/comparator runs from the frozen registry.

The complete source tree, raw run files, controller/event logs, baseline profiles, and additional analysis scripts are retained in the supplementary archive supplied with the IEEE submission.

The scripts assume the original project layout under `~/iot-xdp-study`; paths can be adapted when reproducing the analysis elsewhere.

See `../REPRODUCIBILITY.md` for evidence scope and interpretation boundaries.
